# KuroCat 5.2.0 · 照相馆升级

这一版把「照片 → 猫」做深，并补上了自定义、键盘阵列、鼠标样式和多物种。

## 识图

- 按**头部 / 躯干 / 腹部 / 四肢 / 尾巴**五个部位分别取色，再汇总成外观参数。
- 新增 **8 个品种候选**：中华田园、橘猫、奶牛、三花、英短蓝、美短银渐层、布偶、暹罗。给出匹配度（如「奶牛猫 87%」），点一下即套用该品种的配色、花纹与脸型。
- 背景剔除改为「画面外圈 15% 边缘带」判定，纯色墙、白底、木桌都能识别掉，不再把背景串成毛色。

## 自定义

- 工坊分**简易 / 高级**两档。
- 高级面板按**耳朵、头部、四肢、尾巴、躯干**五组展开：耳内 / 耳外 / 耳尖、面罩 / 鼻梁 / 胡须、手臂 / 爪子、尾巴 / 尾尖、侧腹 / 腹部 / 条纹 / 斑块。
- 没有单独指定的颜色会标成虚线并继承毛色。

## 换岗动效

切换猫咪时会随机播放一个：**敬礼、互相哈气、谁也不理谁、比爱心**，各配一句气泡。2D 四种齐备，3D 有敬礼与比爱心。
也可以在 MCP / 状态钩子里直接触发：`salute` / `hiss` / `ignore` / `heart`。

## 键盘阵列

从 2 种扩到 4 种：**65% 紧凑、75% 便携、87 TKL、108 全尺寸**。2D 与 3D 同步，窗口尺寸随布局自动调整。
托盘菜单与 MCP 的 `keyboardLayout` 同步支持 `65 / 75 / 87 / 108`。

## 鼠标样式

8 款配色：经典白、曜石黑、樱花粉、薄荷绿、电光紫、奶茶棕、冰川蓝、余烬橙。
按「猫 id + 种子」分配，所以**每只猫天生一个固定样式**；设置里点 🎲 换一个即时重掷。

## 多物种（原型）

- 「物种」可选：**猫 / 蛇 / 鸡**。
- **蛇**：盘成三圈，靠蛇尾敲键盘、推鼠标。
- **鸡**：橙爪踩键，鸡冠与喙会随打字动作开合。
- 蛇与鸡目前走 2D 渲染（3D 模型暂缺），其余能力（气泡、状态、动效）与猫一致。

## 兼容性

- Windows 10/11（x64，NSIS 安装包）、macOS 10.15+（Universal，ad hoc 签名）、Linux（amd64 / arm64，AppImage 与 deb）。
- 安装包请放在**不含中文的路径**下运行（NSIS 限制）。

## 已知限制

- 蛇 / 鸡是原型，只有 2D；操作方式复用猫的按键目标，不做单独的手势。
- 背景与猫毛色接近时，仍可能需要手动改一下毛色。
- macOS 为 ad hoc 签名，首次打开需右键 →「打开」，或执行 `xattr -dr com.apple.quarantine /Applications/KuroCat.app`。
