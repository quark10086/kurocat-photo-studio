# v5.3.1 · 稳定性修复

v5.3.1 集中修复 macOS 输入、换猫交接和 75/87 键鼠布局的问题，不引入新玩法。

## 一、macOS 全局键鼠恢复

- **签名改为稳定的 ad-hoc 指定要求**：不再把 TCC 授权钉在每次构建都会变的 cdhash 上，覆盖安装或重新构建后，辅助功能 / 输入监控授权不会悄悄失效。
- **新增无权限轮询兜底**：用 `CGEventSourceKeyState` / `CGEventCreate` 读取全局键盘和光标位置，这两个 API 不需要 TCC 授权；事件通道恢复后自动让位，滚轮和零延迟按键仍走原来的事件通道。
- 新增 `npm run build:mac`：构建 `.app` 后自动重新签名；本地构建不再需要手动跑签名脚本。
- README 补充 macOS 构建与重新授权说明。

## 二、换猫交接与切回 3D

- 交接动画全程保持 60fps，不再在 2.2 秒后掉到低帧率档位。
- 旧猫身体在交接开始时预渲染为离屏精灵，交接期间只做平移/旋转/淡出，不再每帧重绘两只猫；呼吸用轻微纵向缩放保留。
- 3 秒结束切回 3D 时走快速路径，跳过重复的 3D 状态同步；同时去掉重复的 `renderer.setSize`，避免同一帧两次重分配 WebGL drawing buffer。
- 交接结束后延迟释放旧猫精灵，避免在切回 3D 的那一帧同步释放后备存储。

## 三、窗口离屏保护

- 启动时如果保存的窗口坐标已经完全离开所有显示器，自动重新摆到当前屏幕内，并写回设置。
- 键盘布局/缩放变化导致窗口 resize 时，把新位置限制在当前显示器范围内，避免连续切换把窗口“走”到屏幕外。

## 四、75/87 键鼠布局

- 3D 鼠标位置改为按键盘左缘计算，不再和 75/87 键盘重叠。
- 2D 布局同步调整 75/87 的鼠标基准位置。
- 3D 摄像机改为按实际键盘右缘和鼠标左缘取景，修复 75/87 鼠标被画布左边缘裁切的问题；65/108 也使用同一套自适应逻辑。
