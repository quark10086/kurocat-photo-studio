# v5.1.3-photo — first release of KuroCat Photo Studio

KuroCat Photo Studio 是 [qianyiai/kurocat](https://github.com/qianyiai/kurocat) 的衍生版本。
本次发布在完整保留上游 v5.1.3 功能的基础上，加入「从图片创建我的猫」。
This release is the first build of KuroCat Photo Studio, a derivative of KuroCat v5.1.3 (MIT) that adds a
photo → cat-appearance feature.

## 新增 / Added

- **从图片创建我的猫**：右键猫咪 →「角色外观」→ `📷 从图片创建我的猫`
- 「猫咪工坊」：选图 → 本地分析 → 实时 2D 预览 → 8 项微调 → 保存并应用
- 分析完全在本地前端完成（Canvas 2D + k-means + 外圈 15% 边缘带背景剔除），不联网、不上传
- 生成结果同时驱动 2D（Canvas）与 3D（three.js）两套渲染
- 5 种语言的新文案（zh-CN / zh-TW / en-US / ja-JP / ko-KR）

## 兼容性 / Compatibility

- Windows 10 / 11 x64：本安装包即在此环境构建与测试
- macOS 10.15+：代码层面已确认（`createImageBitmap` 有 `<img>` 回退），但本仓库**未提供** macOS 产物；请自行执行
  `npm install && npm run build && npm run tauri:build`
- Linux：未验证

## 安装 / Install (Windows)

1. 下载 `KuroCat_5.1.3_x64-setup.exe`
2. 运行安装（per-user，安装到 `%LOCALAPPDATA%\KuroCat`）
3. 首次启动若出现 SmartScreen 提示，是因为**没有代码签名证书**：更多信息 → 仍要运行

校验和：

```

大小    2,434,161 bytes
```

## 已知限制 / Known limitations

- 背景与毛色接近时可能偏色，可用「毛色」控件修正
- 虎斑条纹、重点色为启发式判断，可能落到纯色/双色，可用「花纹」下拉框切换（会自动补齐条纹/斑块颜色）
- 只推断静态外观，斑块按规则生成（上限 16 个）
- 安装包未签名
