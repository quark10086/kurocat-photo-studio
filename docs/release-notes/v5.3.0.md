# v5.3.0 · 互动升级

v5.3.0 把「桌宠对你有反应」这件事做实了：三种由真实输入驱动的互动，加上换猫时的双猫交接。

## 一、双猫交接（换岗动效升级）

- 以前的换猫只有一句气泡，现在**两只猫同屏演出**：旧猫从左侧滑入、在左侧站定并向新猫致意，然后向左退场淡出；新猫在右侧接岗，中间浮出一个动作符号。
- 交接期间整个画面像镜头一样向右平移约 58px，给旧猫让位，两只猫因此并排站开而不是叠在一起；结束后画面自动回中。
- 两只猫都由**同一套 2D 渲染引擎**绘制，所以和桌宠本身的美术完全一致；旧猫保留自己的毛色、花纹与眼色（奶牛猫换黑猫时一眼能看出是两只不同的猫）。
- 如果当前是 3D 渲染，交接时会临时切到 2D 播完再切回 3D —— 三段式：进场（0–30%）→ 对峙致意（30–66%）→ 退场（66–100%），总长 3.2 秒，期间点击不打断。
- 四种交接风格随机：🫡 互相致意 + ✨、💢 互相哈气、💤 谁也不理谁、💗 比爱心；配合一句对应气泡。

## 二、三种由输入驱动的互动

| 互动 | 触发条件 | 表现 |
| --- | --- | --- |
| 打字太久会抗议 | 连续打字 25 秒（停顿超过 1.2 秒算中断） | 眼睛变凶、冒出 💢、抬爪离键，配一句「打字太快啦…」+ **温和的抗议低音**（低通滤波的 sine + 三角波，全程避开刺耳高频）；冷却 3 分钟，不会反复唠叨 |
| 困了打哈欠 | 键盘鼠标 90 秒无动作 | 眯眼张嘴打哈欠 + 「好困…」，配**吸气与叹气**的合成音 |
| 被摸会开心 | 光标在猫身上停留 1.5 秒 | 眯眼蹭手心、爱心飘起 + 「再摸一下…」，配**满足的呼噜+两声轻哼**（上升音，猫开心时的音色）；6 秒内不重复 |

- 三种互动都受「声音开关」「隐私模式（输密码）」「游戏模式」约束：隐私与游戏时不会打扰。
- 音效全部是 WebAudio 现场合成（振荡器 + 噪声 + 滤波 + 包络），**不下载、不打包任何音频文件**，因此体积不增、也没有版权问题。

## 三、其它改动

- **移除蛇 / 鸡多物种**：v5.2.0 试做的两套形体因动作与比例不达预期，已从源码、界面入口与内置数据中整体删除。角色外观恢复为 7 只猫 + 大肥鱼。
- 修复：桌宠窗口在显示器布局变化后可能被记到屏幕外（表现为右键没反应），现在启动时会校验位置。

## 兼容性

- 外观数据 `cats.json` 只增不删：旧的自定义猫（含带 `species` 字段的）仍能读入，缺的字段按默认值补齐。
- 键盘阵列 65 / 75 / 87 / 108、鼠标 8 款随机配色、识图与工坊均不受影响。

## 已知限制

- 交接时桌宠会临时切到 2D 渲染（为保证两只猫美术一致），播完自动回到原来的渲染模式。
- 互动的阈值是固定默认值，暂未开放设置项。
